# 信息图形设计知识库

本仓库用于持续积累信息图形（Infographics）的数据逻辑、统计转译、视觉编码、信息架构、视觉叙事方法与案例。

## 目录

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：五种基础数据逻辑及其设计方法。
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：按表达类型整理的案例分析与方法总结。

## 工作原则

1. **案例驱动**：案例文档中的具体判断以用户提供的案例图及其可辨识信息为依据。
2. **区分事实与推断**：图中可见内容、对数据关系的解释、设计推断分别标注；无法确认的数据不臆测。
3. **持续迭代**：新增案例后，更新对应案例文档，并回看01目录中的数据逻辑、视觉编码和叙事原则。
4. **交叉引用**：01目录只写抽象方法与概念，不保存案例图片；通过相对路径链接到02目录的案例分析。
5. **统计诚实**：说明数据来源、统计口径、单位、时间范围及必要的计算方法；装饰性视觉不能暗示不存在的数据精度。

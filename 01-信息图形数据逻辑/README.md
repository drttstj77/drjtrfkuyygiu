# 01 信息图形数据逻辑

本目录讨论信息图形背后的组织逻辑，而非单纯罗列图表样式。每篇类型定义统一回答五个问题：

- **A 基本数据逻辑**：什么样的数据结构、实体关系或组织规则构成该类型的本质？
- **B 统计图形与计算方式**：借用了哪些统计图形、统计口径、排序或计算方法？哪些是必要的，哪些只是可选工具？
- **C 视觉编码**：点、线、面、体、符号、文字、色彩、尺度、位置、纹理如何编码信息？
- **D 数据／信息架构**：信息如何分组、分层、排序、建立索引及形成阅读路径？
- **E 视觉叙事架构**：读者从哪里进入，如何理解关系、发现重点并获得结论？

## 方法论边界

- 五种逻辑是分析和组织信息的基本模型，不代表所有作品只能归入一种类型。
- 作品可以有主导逻辑与辅助逻辑；混合型作品应说明各逻辑承担的表达任务。
- 统计图形是信息转译工具，不等同于信息图形本身。信息图形还包含符号系统、视觉编码、信息组织和叙事设计。
- 具体作品是否符合某项原则，须由案例图、图中文字及可核实的数据共同支持。

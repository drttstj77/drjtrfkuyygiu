本目录保存由用户提供的案例图及其分析总结。案例分析先描述可见结构，再解释其数据逻辑、统计转译、视觉编码、信息架构与叙事方式；不根据风格印象臆测不可见的数据或来源。

## 案例分析模板

每个案例建议记录：

1. 案例编号、标题、来源／作者、发布时间、用户提供日期。
2. 原图或文件引用（图片保存在本目录的案例资源位置；不复制到01目录）。
3. **图像观察**：版面结构、图表类型、符号、颜色、文字和阅读顺序。
4. **数据逻辑**：实体、字段、分类、时间／空间／层级关系。
5. **统计转译**：采用的统计图形、计算方法、尺度和统计口径；未知项标记“待核实”。
6. **视觉编码**：点、线、面、体、符号、色彩、字体、尺度和图例。
7. **信息架构**：分区、分组、排序、索引、层级与导航。
8. **视觉叙事**：入口、阅读路径、重点、转折、结论与行动提示。
9. **可迁移原则**：适用条件、操作方法、限制和反例风险。
10. **关联理论**：链接到01目录对应的概念定义文档。

## 持续更新机制

新增案例后：
- 在对应类型文档新增案例记录，并给案例编号。
- 将反复出现且有充分案例支持的方法归纳为“观察到的共性”。
- 对存在差异的做法记录其适用条件，不强行归纳成单一规则。
- 更新01目录相关定义文档中的设计原则，并链接回案例。
- 保留版本／更新记录，避免把单一案例的特征误写为普遍规律。

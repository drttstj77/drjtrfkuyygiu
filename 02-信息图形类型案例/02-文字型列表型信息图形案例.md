# 02 文字型／列表型信息图形（Informational / List Infographics）

## 类型定义与分析范围

文字型／列表型信息图形以文字条目、短说明、标签、编号或清单为主要信息载体，通过排版、图标、分组、色彩和空间组织，使内容易于扫描、记忆和检索。它并不意味着“只有文字”，而是以文字信息单元作为内容骨架，图像、图表和路径负责辅助识别、比较与导航。

PDF第23页将此类作品称为Informational / List Infographics，并展示了人物主题信息图和报纸版面叙事两个不同方向：前者是多模块信息清单，后者通过一条连续视觉路径组织长篇文字。

## 案例一：The Beatles人物主题信息图

**来源定位：**《第三讲-信息图形类型学.pdf》第23页左侧案例，画面标题“Los Cuatro Genios / The Beatles”。

### 图像观察

画面以披头士乐队人物肖像为中心，周围分布成员姓名、人物简介、符号化标识、小型饼图／统计图、人物关系或成员信息，以及底部多个表格／列表模块。中央肖像提供主题识别，周边模块将一个主题拆分为多个可扫描的信息单元。

### 数据／内容逻辑

该作品具有“中心主题＋多条目分组”的结构：
- 中心对象：乐队整体及其人物身份；
- 子条目：成员个人信息、简介、特征或相关内容；
- 统计／比较模块：以小型图表和表格呈现可比较的属性；
- 视觉识别模块：成员头像、符号和名称建立人物对应关系。

图中各指标的确切含义和数值口径在PDF缩略图中不能全部辨认，需查看原始清晰图或来源才能确认；本分析不推定其统计内容。

### 图形与统计方式

可见小型饼图、条形／表格类信息模块与图标化人物表达。它们承担不同任务：
- 饼图：可能表达组成或比例，需有完整类别和图例；
- 条形／表格：支持成员或属性之间的比较；
- 人物符号与肖像：建立对象识别，不等同于统计数据；
- 文字简介：补充背景和定性信息。

### 视觉编码

- **中心大图像**：以人物肖像建立视觉入口和主题焦点。
- **周边卡片／分区**：把成员和主题拆分为独立信息单元。
- **人物符号**：辅助区分成员或相关对象。
- **小型统计图**：在有限空间中嵌入定量信息。
- **字体层级**：标题、成员姓名、说明文字与图表标签形成不同阅读级别。
- **色彩**：用于分组和强调，但不同模块的颜色具体含义需要图例确认。

### 信息架构与视觉叙事

阅读顺序并非完全线性：读者先通过中心肖像识别主题，再向周围成员模块扩散，最后浏览底部表格或补充信息。这种布局形成中心辐射式探索路径，适合主题明确、内容多元但具有共同对象的信息。

### 可迁移原则

1. 当多个条目共享一个中心主题时，可用中心图像建立入口，周边模块承载不同信息类别。
2. 每个模块采用一致的标题、说明、数据和图例结构，降低切换成本。
3. 中心图像是视觉入口，不应挤压条目文字和数据标签的可读空间。
4. 统计图、肖像和装饰图标应在语义上区分，避免把装饰误读为数据。
5. 模块数量增加时，必须建立清晰的分组和视觉导航。

## 案例二：报纸版面中的蛇形路径叙事

**来源定位：**PDF第23页右侧案例。图像为报纸版面，中央有一条蜿蜒的粗白色路径，连接多个文字说明区域。

### 图像观察

作品保留报纸的多栏文字结构，以一条连续、曲折的路径穿越版面。路径在视觉上形成强烈主线，读者可沿路径从上至下或按路径转折阅读，文字块作为沿途的信息节点。路径旁的标题和注释补充主题语境。

### 内容逻辑与信息架构

此案例以“连续路径＋分布式文本节点”组织内容。路径负责串联信息块，形成顺序性阅读体验；文字仍是主要信息载体。其结构接近视觉化文章或导览式清单，不必然是严格的流程图：只有当路径节点之间存在真实步骤或因果关系时，才应解释为流程。

### 视觉编码

- **粗路径线**：作为阅读导航和版面主视觉。
- **文字栏／文字块**：承载主要事实与说明。
- **路径转折**：制造节奏并引导视线，但不自动表示数据变化。
- **黑白对比**：突出主路径，保持报纸文字的可读性。
- **标题与旁注**：提供主题入口和局部解释。

### 可迁移原则

- 连续路径可用于串联分散文字，但路径方向必须清楚，避免阅读顺序歧义。
- 路径的视觉吸引力应服务于信息导航，不能遮挡正文。
- 若路径只是版面动线，不应使用流程图式箭头暗示因果或操作步骤。
- 长篇文字需要足够字号、行距和分段；路径设计不能以牺牲阅读舒适度为代价。

## 文字型／列表型信息图形的结构模型

### 1. 条目型

由多个并列信息单元组成，适合清单、知识点、人物档案和属性目录。重点是条目模板一致、分组明确、扫描快速。

### 2. 中心辐射型

以一个主题、人物或对象为中心，周边分布相关条目。适合多维介绍同一对象，但需控制连接关系和模块数量。

### 3. 路径导览型

通过连续线条、编号或版面动线串联文字节点。适合长篇内容的分段阅读，但须区分“阅读导航”与“真实流程”。

### 4. 图文混合型

文字作为解释主体，图表、图标、照片和插画提供证据、识别或语境。图像应有明确功能，不能仅为了装饰而重复文字。

## 综合设计原则

- **先拆分内容，再设计版式**：先明确每条信息的主题、类别和相互关系，再决定列表、卡片、中心辐射或路径布局。
- **维持条目一致性**：同级条目尽量使用相同的信息字段顺序和排版模板。
- **控制信息密度**：密集内容可通过分组、留白、标题和局部导航组织，不要简单删除有价值的信息。
- **让图标承担明确语义**：图标可以表示类别、对象或状态；若代表数量，需明确一图标对应多少单位。
- **尊重读者能力**：不要假设读者只能理解极简内容；应通过层级和导航帮助读者自主深入。
- **简化形式而非简化事实**：可减少无意义装饰，但不应删掉理解主题所必需的复杂信息。

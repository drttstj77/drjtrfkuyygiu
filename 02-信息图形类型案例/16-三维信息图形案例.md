# 16 三维信息图形（3D Infographics）

## 来源与定位
- 来源：《第三讲-信息图形类型学.pdf》第38页。
- PDF原始标题：3D Infographics。课件页未提供更多可确认的文字定义。

## 工作性定义
三维信息图形利用透视、立体模型、空间体块、深度、体积或三维场景呈现对象、数据或空间关系。三维可以是实际三维模型，也可以是二维页面中模拟的立体视觉效果。使用三维并不自动意味着数据具有真实的三维测量维度。

## 核心结构
主题对象／数据 → 三维空间或体块组织 → 视角与尺度 → 标注／图例 → 读者观察路径。需明确三维表达的是对象结构、空间位置、体积数据还是纯视觉风格。

## 视觉编码
透视、深度、体积、明暗、材质、遮挡和空间位置均可参与表达。若体积代表数量，应建立清楚的数值映射；若仅为示意模型，应标明非比例或非真实空间关系。

## 适用情境
建筑与城市空间、产品结构、科学对象、空间数据、复杂系统模型和需要立体呈现的对象说明。

## 设计检查
1. 三维维度是否承载真实信息，而非纯装饰？
2. 透视是否导致前后对象产生不公平比较？
3. 体积编码是否容易被误读，是否有明确图例？
4. 遮挡是否隐藏重要信息？
5. 是否提供合适视角、标注和必要的二维辅助视图？

## 与其他类型的边界
三维是视觉表达维度，可以与解剖结构、地理、流程、层级或混合图表结合。判断类型时需区分“立体风格”与“信息本身具有空间维度”。
